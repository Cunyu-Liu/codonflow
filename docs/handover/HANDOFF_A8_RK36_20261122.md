## 0. 为什么做 RK36（核心指令）

交接提示词 §三/§四 明令：**RK34 是同队列切窗消融的终点；RK35 起必须做真正独立验证或转向**，不得继续在 Kudla 同队列切窗。/goal 判定（goal check 1/3）指出 RK35 仍是同队列 Kudla 覆盖消融，核心指令未满足。RK36 因此执行 §四 mandated 第一步——**标签无关独立运输可行性审计**：在读取任何结局之前冻结合格要求，审计是否存在能重建 Kudla 精确天然起始窗 `UTR[-4:]+CDS[:38]`、做固定蛋白同义运输的独立完整 CDS 功能数据。

§四 决策规则：① 若有合格独立数据 → branch1 运输预注册；② 起始覆盖贡献不成立/不可判别 → 停止 start-aware MFE 当核心，转向翻译动力学/功能序列模型；③ 独立数据不存在 → branch3 记录 feasibility + 缺失维度，**不得用不同宿主/assay/覆盖数据集假装回答，不得为阳性读 functional untouched**。RK34 联合精确上下文增量成立但分离上游/起始不可识别 → branch1 触发；RK23+RK25 跨蛋白跨宿主运输失败 → branch2 也触发。

## 2. R1–R7 合格要求（冻结）

- R1 独立研究/宿主（非 Kudla 训练队列）
- R2 每变体完整 CDS
- R3 变体特异天然 5'UTR（ATG 上游≥4nt），可精确重建 `UTR[-4:]+CDS[:38]` 同构建几何（固定载体 leader 替代不算）
- R4 固定蛋白同义库（跨蛋白天然非 synonymous 池不算）
- R5 蛋白身份 + family 映射，可做蛋白/研究 OOD
- R6 新鲜连续结局，动态范围充足（粗 ordinal 不算）
- R7 序列簇/蛋白/研究隔离可行 + license/accession/raw SHA 可文档化

合格 ⟺ R1–R7 全 PASS；≥1 → branch1；0 → branch3 记录缺失维度 + 触发 branch2 转向。
