## 1. 冻结协议与比较臂

协议：`configs/a8_rk41_internal_basin_protocol_v1.json`
protocol_id=`RK41_INTERNAL_BASIN_INITIALIZATION_V1`
SHA256=`9ed2657dfe698bc096eb1e1fe853a723f26bd69dcd3b0bc768e4f946412dc83a`
预注册：`audits/20261122/RK41/A8_RK41_PREREGISTRATION.md`；冻结提交 `49017ae4b031f6b502b3b3b8d5dec990d26682e8`。

18 development records × 3 seeds，每 record/seed 生成八个不同的 protein-only 同义初始化并全部真实评分。`first` 取 index0；`best` 按对应搜索 utility 选择，平票取最低 index。选中起点计为 cache hit，随后只增加三个唯一局部搜索点，总预算精确为11；重复提案不耗预算。

四个新臂：

1. `raw_pool_first_b11`；
2. `raw_pool_best_b11`；
3. `calibrated_pool_first_b11`；
4. `calibrated_pool_best_b11`。

raw 臂搜索时不读取 native calibration；calibrated 臂只诊断尺度交互。四个新臂不使用 LinearDesign、EnsembleDesign、天然同义 DNA 或其他外部序列；同一 record/seed 共享初始化池和局部搜索 RNG。另接受 RK40 已独立验证的108个 `raw_random_b11` 与 `calibrated_random_b11` runs，总分析324 runs。

三个 primary families：

- `basin_selection_raw`：raw best−raw first；best normalized weighted utility 与 best single-point normalized HV；
- `sequential_advantage_raw`：raw best−raw random B11；同上两个内部终点；
- `common_input_external`：raw best−LinearDesign-11；record-specific first-k actual-set HV 与 pairwise NED。

统计单位为 record，先平均三个 seed，再进行20,000 paired bootstrap 与20,000 sign-flip；每 family 双终点 Holm。通过要求 CI 下界>0、Holm p<0.05且三个 seed 效应均为正；external family 要求两个终点同时通过。
