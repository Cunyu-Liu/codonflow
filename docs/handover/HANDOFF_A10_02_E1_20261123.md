### 2.3 可声称与不可声称

可声称：在限定开发研究中，低自由度观察校准相对两种 raw 对照稳定降低 TB-MSE，构成 H1 观察过程可分性的开发证据。

不可声称：

- 最终跨研究运输或真实生物泛化已经成立；
- occupancy 是绝对物理速率，或校准已证明动力学机制；
- Pearson/Spearman 有所改善；
- H2、E2/G1、E3/G2 或 SOTA 已通过；
- 可以据此读取最终 untouched 或启动生成训练。

最终未读跨研究评估仍须另选合格研究，在读取 target test outcome 前冻结 source train、独立 target calibration、target test、统计和成本协议。开发结果不得外推为最终跨研究结论。

### 3.2 距离 E2/G1 完成仍缺什么

1. 完成严格为正的起始率、逐位延伸率和终止率的完整参数化；不得添加无数据支持的 decay 或远程 pair 头。
2. 完成稳态残差、通量守恒、边界、梯度、参数可辨识性和平均场近似误差的完整验收。
3. 在匹配输入、参数量和训练预算下，对比完整动力学、去流守恒同容量模型、独立密码子模型和纯位置场。
4. 在 transcript/变体 OOD 检验局部编辑上下游密度响应、通量变化与主指标，先完成局部敏感性和可辨识性，不直接扩大训练。
5. 报告至少 3 seeds、逐转录本方向、paired cluster bootstrap 95% CI、Holm、效应量、失败分层和完整成本。

只有严格 OOD 稳定超过去守恒与简单模型，才可判定 G1 通过并将相应动力学量送入 E3。若无独立增量，按合同删除动力学核心并停止 Kinetic-CodonFlow 主线，不增加模块救场。
