## 2. 已实现的 A7 协议组件

- `src/codonflow/eval/anytime.py`：独立 calibration 的 FrozenReference、固定参考域 HV、anytime curve/AUC，退化轴拒绝。
- `src/codonflow/models/simple_search.py`：uniform、hill-climbing、MH/annealing、AReUReDi-style；同义操作符、唯一 scorer 预算、成本 trace。搜索效用和 AUC 共用独立归一化，避免 MFE 原始尺度主导。
- `src/codonflow/eval/paired_stats.py`：seed 先在基因内聚合，基因级 paired bootstrap、Wilcoxon、Holm。
- `src/codonflow/eval/protocol.py`：A7 结果元数据、逐点预算和成本 schema。
- `scripts/a7_data_audit.py`：无效原因、长度/GC/CAI/RSCU、物种/簇元数据、cleaning manifest 守恒。
- `scripts/a7_build_confirmation.py`：不用模型目标，按长度/GC 分层并排除旧 ID、精确 CDS/蛋白和同源簇；缺失 cluster 映射直接失败。
- `scripts/a7_build_calibration.py`：只从独立 calibration 目标向量生成 reference/scale。
- `scripts/a7_run_simple_search.py`、`scripts/a7_compare.py`：真实 scorer 运行与基因级聚合入口。
- `configs/a7_protocol.json`、`configs/a7_data_protocol.json`：预算、统计、阈值和数据源状态冻结。
