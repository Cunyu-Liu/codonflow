发现一个会直接卡住 G2 的问题：`scripts/run_a6_rollout_pilot.py` **只接受单条 CDS 的 FASTA**

处置：
1. 给脚本加 `--record-id`：多记录 FASTA 里按 header 精确选一条；不给就仍要求单条。
2. 实测三遍：
   - smoke A（不带 `--record-id`）：按预期报 `pilot requires exactly one source CDS (use --record-id to select one)`；
   - smoke B（`--record-id egfp_P42212_syn`，4 解 / T=2 / C=2 / R=2，用 `a6_v4_56m_r2/best.pt`）：
     `RC=0`，成本字段正常输出（`rollout_state_transitions=40`、`terminal_reward_evaluations=44`、`unique_terminal_reward_calls=37`）；
   - `py_compile` 通过。
3. 产物 `eval_outputs/a6_pilot/runbook_smoke_20261031.json` **只是接口冒烟**，不是算法结论，不得引用其 HV。
